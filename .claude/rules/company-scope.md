# 会社

**`issuers` が「会社」そのもの。** 個人事業と法人のように、
複数の会社の帳簿を1つのアプリで分けて持つ。

- **選択の実体**は Cookie `keiri_company`。`lib/active-company.ts` の
  `loadCompanyContext()` が解決し、`companyScope()` が Repository へ渡すフィルタを作る。
  DB に持たせないのは、これが「今どちらを見ているか」という端末側の表示状態だから
- **切替 UI** は `components/company-switcher.tsx`。Server Action
  `app/_actions/company.ts` が Cookie を書いて `revalidatePath("/", "layout")`

## スコープが効く面と効かない面

|                | 対象                                                                                                                                                                                                    |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 会社ごと       | 帳票・売上台帳（`revenues`）・経費・レポート・ホーム・AI 改善提案・会計帳簿（`/accounting`）・決算（`/closing`）。現金残高は `cash_balance:<issuerId>`                                                  |
| 会社をまたぐ   | お金コーチ、プッシュ通知、エージェント向けのお金 API。**これらは会社の帳簿ではなく本人のお金を見る面**                                                                                                  |
| 会社の列が無い | 銀行明細（`bank_transactions`）。会計帳簿では「会社が未設定の既存データ」と同じ扱いにし、既定会社を見ているときだけ仕訳に入れる（`app/accounting/_lib.ts`）。銀行明細の照合候補の請求書は会社で絞らない |
| 共有           | 取引先（`parties`）。同じ取引先を両社で使うため                                                                                                                                                         |

書類作成 API（エージェント用）は、`issuerId`（省略時は既定会社）で指定した会社の帳簿に書く（`agent-api.md`）。

会社ごとの決算月（`fiscalYearEndMonth`）と第1期の期末日（`firstFiscalYearEnd`）は `issuers` の N・O 列。
決算（`domain/fiscal-year.ts` の第n期）と、会計帳簿の期首の月（決算月の翌月）がこれを使う。

**この線引きを動かさない。** 家計側を会社別にすると、お金コーチが見ている「本人の
手元にいくら残るか」の意味が変わってしまう。

## 既存データ

`Expense.issuerId` は任意（帳票と売上は必ず会社を持つ）。会社スコープ導入前の経費は未設定のままで、
**既定会社を見ているときだけ表示される**（`repositories/scope.ts` の `matchesCompany` に
`includeUnassigned` を渡す）。既存データを書き換えずに移行するための逃げ道なので、
一括で埋める処理を足さない。

## 帳票の発行元は画面で選ばせない

作成時は選択中の会社、編集時は既に属している会社で固定する（`documents/actions.ts`）。
選ばせると、別会社を指定した帳票が**作った直後に一覧から消えたように見える**。

# 採番

**会社ごと・帳票種別ごと**の通し連番（0001…）。カウンターのキーは
`<issuerId>:<帳票種別>`（`repositories/scope.ts` の `counterKey`）。会社が違えば 0001 から始まる。

次の番号は `nextSequence(カウンター値, 発行済みの最大番号)` で決める。カウンター行がまだ
無い会社でも、既存帳票の最大番号から続きを振るので、会社スコープ導入前の番号と連続する。

<important if="採番のロジックを変えるとき">
**同じ規則が `scripts/keiri.mjs`（CLI）にも実装されている。**
片方だけ変えると、画面と CLI が同じ番号を二重に振る。必ず両方を同時に直す。
</important>
