## 重要な判断基準

- 会議費 vs 接待交際費：1人 ≤ 1万円(税込)＆打合せ → 会議費。1人 > 1万円・接待/贈答 → 接待交際費（**全額**が交際費）。社内のみは金額不問で会議費。
- 消耗品費 vs 固定資産：物品 < 10万円 → 消耗品費。**10万円以上 → 要確認**（一括償却/少額減価償却特例/工具器具備品の判断が要る）。
- SaaS/サブスク：原則 通信費。決済・取引手数料 → 支払手数料。学習コンテンツ → 新聞図書費/研修費。一度決めた科目は継続使用（継続性の原則）。
- 按分（家賃/通信/車両/光熱）：カード明細では科目だけ決め、事業割合の按分は別途手動。
- 雑費は経費総額の 5〜10% 以内。事業性不明・私的疑い・高額は雑費でなく**要確認**へ。
