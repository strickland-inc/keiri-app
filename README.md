# keiri-app

見積書・請求書の作成から、経費の記録、会計帳簿、決算の準備までを1つにまとめた経理アプリです。

データはご自身の Google スプレッドシートに保存されます。インターネットへの公開先は Cloudflare Workers です。

## 要約

- 簡潔に言えば、freee のような会計ソフトを、自分の Google スプレッドシートの上で動かすアプリです。
  - 請求書と経費から仕訳を自動で作り、貸借対照表・損益計算書・総勘定元帳まで画面で見られます。
  - クレジットカードの利用通知メールが届くと、その支出が自動で経費に入ります。いま対応しているカードは楽天カードです。
  - 銀行口座とは直接つながりません。銀行のサイトから明細の CSV を落として読み込ませます。確定申告の書類の作成もできません。
- 個人での利用から、法人としての利用までできます。1つのアプリで、複数の会社の帳簿を分けて持てます。
- 下の枠の中の文章を Claude Code や Codex に渡して、導入してみてください。
  - ※ API キーと各サービスのアカウントは、ご自身で用意してください。

## このアプリは何ができるか

### 見積書・請求書などを作る

見積書、請求書、納品書、発注書、領収書を作れます。番号は会社ごと・種類ごとに自動で振られるので、手で番号を付けて間違えることがなくなります。前に作った書類をコピーして、新しい書類を作ることもできます。PDF でダウンロードでき、送るときのメールやチャットの文面もコピーできます。

### 経費を自動で記録する

楽天カードの利用通知メールを1時間ごとに読み取り、経費に入れます。PayPay や楽天カードの明細ファイルからも取り込めます。紙の領収書は、スマートフォンで撮影すると AI（Gemini）が日付・店名・金額を読み取ります。

### 経費の勘定科目を自動で仕分ける

「旅費交通費」「会議費」などの勘定科目を、店名から自動で判断します。一度直した店は覚えるので、使うほど手直しが減ります。

### 銀行明細を取り込む

銀行のサイトから落とした明細の CSV を、銀行名を選ばずにそのまま読み込めます。入金は未入金の請求書と自動で突き合わせ、残りの行は AI（TypeSafe の Jev）が勘定科目を選びます。自信のない行は「要確認」として残します。

### 会計帳簿を見る

請求書・経費・銀行明細から仕訳を自動で作り、貸借対照表、損益計算書、月ごとの損益、仕訳帳、総勘定元帳を画面で見られます。

### 売上とお金の流れを見る

売上の記録、月ごとの収支、よく使うお店のランキングを画面で確認できます。週ごと・月ごとのまとめをメールで受け取ることもできます。

### 決算資料を出す

事業年度ごとの決算資料と試算表を出せます。freee会計に取り込める形式の CSV も出せるので、税理士さんや freee へデータを渡せます。

### 複数の会社を切り替える

個人事業と法人など、複数の帳簿を1つのアプリで持てます。メニューで会社を選ぶと、書類・経費・会計帳簿・決算がその会社のものに切り替わります。

### スマートフォンで使う

ホーム画面に追加して、アプリのように使えます。

## このアプリを導入するとどのようにビジネスは変わるか

### 請求書づくりの手間

請求書づくりは数分で終わります。取引先と明細を選ぶだけで、番号の付いた請求書ができます。Excel のひな形をコピーして番号を手で直す作業がなくなります。

### 月末の領収書の整理

カードで払った経費は、通知メールが届いた時点で帳簿に入っています。月末にレシートを集めて打ち込む時間が減ります。

### 月の途中の収支

経費と入金が毎日たまっていくので、いまいくら使っているか、利益がいくら出ているかが、月の途中でも分かります。使いすぎに早く気づけます。

### 決算の準備

決算の前に慌てずに済みます。1年分のデータが勘定科目ごとに整理され、貸借対照表と損益計算書の形で残ります。税理士さんへ渡す資料や freee への取り込みが、まとめて用意できます。

### データの置き場

データはご自身の手元に残ります。帳簿はご自身の Google スプレッドシートに保存されます。サービスの終了や値上げで、データを取り出せなくなる心配がありません。

## Cloudflare に公開する手順

スマートフォンや外出先から使うために、アプリを Cloudflare Workers に公開します。アカウントの作成とログインは、導入する人がご自身で行います。それ以外のコマンドは、Claude Code や Codex に任せられます。

1. Cloudflare のサイトでアカウントを作ります。無料プランのままで公開できます。
2. `.env.local` に、ログインの設定（`APP_LOGIN_ID`、`APP_LOGIN_PASSWORD`、`AUTH_SECRET`）と Google スプレッドシートの設定を入れておきます。公開先では、スプレッドシートにつながないとデータが残りません。
3. `npx cf auth login` を実行し、開いたブラウザで Cloudflare にログインして、許可のボタンを押します。
4. `npm run deploy` を実行します。`.env.local` の値のうち、アプリが使うものだけがシークレットとして一緒に送られます。値は画面に表示されません。
5. 最後に表示される `https://keiri-app.<あなたのサブドメイン>.workers.dev` を開き、ログインできれば完了です。

本番では、`AUTH_SECRET` が未設定か 16 文字未満だと、アプリはログイン画面も含めてすべてのリクエストを 500 で断ります。誰でもログインの Cookie を偽造できる状態で公開しないためです。500 が出たら、`AUTH_SECRET` を入れて、もう一度 `npm run deploy` を実行してください。

あとからパスワードや API キーだけを入れ替えるときは、`node scripts/set-cloudflare-secrets.mjs` も使えます。このスクリプトは wrangler を使うので、先に `npx wrangler login` でもう一度ログインします。

## 無料プランの制約と料金

Cloudflare Workers の無料プランは、1 リクエストあたりの CPU 時間が 10 ミリ秒までです。このアプリはその枠に収まっていません。開発元が 2026 年 10 月に測ったときは、ログイン画面だけでも CPU 時間の中央値が 14〜22 ミリ秒、スプレッドシートを読む画面は 20〜45 ミリ秒でした。

Cloudflare は多少の超過を許しますが、短い時間に続けて画面を開くと、一部のリクエストが 503 のエラーになります。測ったときは、続けて開いたうちの 1 割強が失敗しました。1 人で普通の速さで使う分には、おおむね動きます。

無料プランは、上限を超えてもエラーになるだけで、料金は発生しません。このアプリは、KV・D1・R2 など課金の対象になる機能を使いません。

安定して使いたい場合は、有料の Workers Paid プランにします。2026 年 11 月に Cloudflare の公式の料金ページで確かめた内容は次のとおりです。

- 月額は最低 5 米ドルで、アカウントごとにかかります。
- 1 か月に 1,000 万リクエストと、CPU 時間 3,000 万ミリ秒までが含まれます。超えた分は、100 万リクエストごとに 0.30 米ドル、CPU 時間 100 万ミリ秒ごとに 0.02 米ドルです。
- 1 リクエストあたりの CPU 時間の上限は、既定で 30 秒になります。

料金は変わることがあります。申し込む前に [Workers の料金ページ](https://developers.cloudflare.com/workers/platform/pricing/) と [上限のページ](https://developers.cloudflare.com/workers/platform/limits/) で確かめてください。
